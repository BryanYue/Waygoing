# Engine 学习资料与渐进教学计划

更新：2026-10-06。适合已有软件工程和 API 经验、尚未系统学过大模型与 Agent 机制的学习者。

这套资料帮助你逐渐回答一个工程问题：**怎样让一个接手任务的 Agent，拿到此刻有效且足够用的项目理解？** 先弄清模型能看见什么、工具怎么运行，再讨论怎样找、存、更新信息。项目地图是待比较的构想，文件搜索、结构化笔记和关系索引都保留为候选。

## 今天从哪里开始

只打开 [第一部分 从一次请求到 Agent 循环](01-model-and-agent.md)，先读到“第一次停下来”。预计 25–35 分钟；做两道短题就可以结束今天这一小段。无需论文、付费 API、模型下载或数据库。

下一次再完成该文的工具往返与迁移练习。第一部分完整学习预计 60–90 分钟，回读和讨论可更长。你不需要一次读完整个资料目录。

练习答案直接发在这个对话里即可，例如：“第一课基础题答案……，实际用了 30 分钟，最不确定的是……”。不必另写报告；我会据此选择下一小段或换一个例子解释。

## 之后怎样跟学

1. 按 [路线与节奏](roadmap.md) 进入下一阶段，每阶段先例子、再机制、最后只读指定来源片段。
2. 需要做题时打开 [贯穿案例与练习](workbook.md)，只看当前阶段的卡片；参考判断放在末尾，先尝试再对照。
3. 到阶段 3 才打开 [论文阅读卡](paper-reading.md)。第一篇只围绕一个问题读，不要求逐页看懂。
4. [材料与来源](sources.md) 是按需书架，列明必学、选学、深入、日期与核查范围。必学共五项外部材料的指定片段，不是五份全文。

## 学习终点怎样判断

学完主线，你应能画出一次 Agent 执行中的信息流；分清“已存储、已取回、已进入上下文、仍有效、已被正确使用”；为需求变更设计一个保留来源的更新流程；解释什么时候图可能有用，什么时候搜索和笔记已够用；读论文时指出它究竟验证了什么。

主线预计约 **17–27 小时**，按 25–45 分钟的小段分散学习。这个区间是教学规划，不是实测承诺；不含深入源码和组件试运行。第一部分做完后按你的实际用时及复述情况调整。没有训练模型的数学先修要求；遇到向量时补“坐标与相似性”，遇到图时补“点、边和路径”即可。

## 资料当前覆盖

第一部分已写成可直接跟学的教材。阶段 3–8 已有路线、来源入口、具体纸面练习和判断标准；后续完整讲义应依据你的答案逐节展开，尚未伪装成已经完成的全套课程。所有练习均为自编教学场景，没有运行 Engine 业务实验。

Codex 和 Claude 通过已安装插件进行了实际讨论。不同观点、来源核查边界及最终取舍见 [讨论记录](discussion.md)；运行证据和作者进度放在 [PROGRESS](PROGRESS.md)，不属于学生必读材料。
