# 第一篇论文怎样读

到路线阶段 3 再读本页。目的不是完整翻译论文，而是能用自己的话说清它提出的问题、采用的方法、依赖的假设、实际实验和结论边界。第一次预计 45–75 分钟，可以分两次。

## 三遍的动作

1. **第一遍 10–15 分钟**：读题目、摘要、引言最后的贡献和一幅主图。写“作者想解决什么”，不抄形容词；不懂的词最多记三个。先不逐行追公式和引文。
2. **第二遍 25–40 分钟**：沿方法和实验设置追一次输入到输出。找谁是对照、改变哪个变量、评价指标怎么算、数据与模型是什么版本。结果图坐标不明白就先读图注。
3. **第三遍 10–20 分钟**：读局限/讨论，再写能迁移到 Engine 的一点以及不能迁移的一点。只有想复用方法时才继续源码和复现。

这是一种课程建议，不是规定必须三遍。背景不够时，只弄懂一个实验就可以暂停。翻译工具可帮助理解句子，但核心结论仍需回对原文，不能让另一个模型的总结替代证据。

## 半填好的第一张阅读卡

来源：Liu 等，[Lost in the Middle v3](https://arxiv.org/html/2307.03172v3)，2023-11-20；首次发布 2023-07-06。下面是课程对指定部分的释读，实验未在本地复现。

| 项目 | 示范或需要你补的内容 |
|---|---|
| 问题 | 模型能接受较长输入时，是否能同样稳定地利用不同位置的相关信息？ |
| 方法 | 观察 Figure 1，读 §2.1：改变相关文档位置或文档数量，查看问答表现。 |
| 假设/条件 | §2 的受控设置中有一篇包含答案的文档；加入若干干扰文档。不要把这等同所有真实搜索结果。 |
| 变量 | 请补：移动文档位置时，哪些内容应保持不变？ |
| 实验 | 请从 §2.2 记一个受测模型名字，从 §2.1 记评价指标的判定方式。名字只用于界定实验，不要求背诵。 |
| 结果 | 请自己看图写两句话；不能只写“有效”“更好”，需写比较对象与变化方向。 |
| 局限 | 模型和任务来自当时设置；不是长期工程交接试验，也没有保证你当前使用的模型复现同一曲线。 |
| 迁移问题 | 可在信息相同而排列不同的材料上比较判断；怎样避免把内容删减和位置改变混为一谈？ |
| 尚未理解 | 最多写三个问题，带原文小节位置。 |

想检查答案时：位置对照中问题、候选文档内容和答案应尽量保持一致；§2 使用答案是否出现在模型输出中的准确性判定，它不自动衡量引用来源是否正确或工程操作是否成功。§3 键值检索与 §5 开放域问答留作可选的第二次阅读，另约 20–30 分钟，不计入这张卡的 45–75 分钟。届时留意任务变了，不能混用结论。

## 下一篇怎样减少扶手

当你能独立填写上表，再选一篇：对检索来源感兴趣选 RAG；对时间事实感兴趣，完成阶段 6–7 后选 Zep。选读是按问题触发，不是升级必须刷的论文数。题目、作者、版本、原文入口见 [来源书架](sources.md)。

使用这张空卡：

```text
论文/版本/阅读日期：
问题：作者在哪个任务里遇到什么失败？
方法：输入 → 处理 → 输出；与已有方法主要差别是什么？
假设：什么数据、监督、工具、预算或稳定性条件必须成立？
实验：数据和模型版本；基线；改变的变量；指标；结果表/图位置。
局限：作者承认什么；你还能指出哪些未覆盖的场景？
可复用部分：帮助 Engine 的哪一环，需接上什么机制？
不能据此声称：哪些整体能力未测试？
下一个最小验证问题：
```

遇到公式，只先标出哪个符号是问题、资料和输出；能描述作用即可。只有方法选择依赖某个公式细节时才补对应数学。读表时区分绝对分数与提升、百分点与百分比；无法核对基线条件时不把数字复制进方案结论。

## 把研究结果放回工程问题

先分清四层：论文报告了某条件下的结果；开源实现提供了一段可复用机制；你在本地跑通它；它改善了真实项目工作。后面一层都需要新的证据，不能由前一层自动推出。

一篇论文的作者也可能是组件供应方。那不自动使结论无效，但需要特别核对实验选择、成本口径、独立对照和迁移缺口。两位模型都认可一篇论文，同样不能替代这些检查。
